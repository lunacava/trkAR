生成用の素材

trkAR で録ったテイクから、参照 (リファレンス) を入れられる動画生成モデルに渡す中間ファイルを作ります。カメラの動きと人の位置はテイクのとおり、見た目は生成で作る、という使い方のためのものです。

  • どのモデルにも寄せていません。条件は「参照の動画と参照の画像を受けて、文章で指示できる」ことだけです
  • trkAR は生成そのものはしません。ファイルをどのモデル・サービスに渡すかは自由です (費用・利用規約はそれぞれのサービスのものに従ってください)

作り方

  1. Blender アドオン trkAR Camera 0.10.21 以降で、テイクを選びます (はじめかた)
  2. 録画・テイク の 生成用の素材を書き出す を押します。横の数字は参照の動画の長い辺 (既定 960)、カメラのアイコンは場所のレイアウトを作るか
  3. 範囲 を入れていれば、その範囲だけを書き出します。モデルの長さの上限 (多くは 5〜10 秒) に合わせてください
  4. テイクのフォルダの中に for_generation/ ができます。もう一度書き出すと、前のものは for_generation_<日時>/ として残ります

できるファイル

ファイル中身モデルへの渡し方
reference.mp4テイクのカメラの動きで、背景のシーンを灰色の粘土 1 色で描いた動画。人は実写から取った白い輪郭線で、中は黒参照の動画 (動き・構図の参照、モーション / ストラクチャーの制御)。プロンプトの <Video 1>
layout.png人の立ち位置から 前 (カメラの奥)・右・後ろ (カメラの方)・左 を見た 2×2 の画像参照の画像 (場所)。<Picture 1>
actor.jpgテイクの実写から、人が大きく・くっきり・明るさの合ったコマを選び、人の外を灰色にした写真参照の画像 (人)。<Picture 2>
prompt.txt上の 3 つを指し示すプロンプトのひな形 (英語)。最後の行に、誰が・何をして・どんな光と雰囲気かを書き足します文章の指示
first_frame.png範囲の最初のコマの実写最初のコマ (画像から動画を作るモデルの開始の画像)
camera.jsonフレームごとのカメラの位置・向き・画角 (Blender のワールド、Z 上、m)カメラの軌跡を受けるツール向け
manifest.json各ファイルの意味・大きさ・fps・フレーム数と、上の当てはめ方スクリプトから読むとき

モデルによって参照の名前 (<Video 1>、@video1、[ref1] など) や、受けられる参照の数が違います。プロンプトの指し方はモデルの説明に合わせて書き換えてください。参照の画像が 1 枚しか入らないモデルなら、actor.jpg を優先します。

うまく作るこつ

  • 人の輪郭線には人物のマスクが要ります。録るときに iPhone の MASK (実写のアルファ) か DPT (人物マスク)、または PC の AI の切り抜き (RVM で切り抜く、はじめかた の「人の切り抜き」) を使ってください。RVM のほうが人の外形が細かく出ます。マスクの無いテイクでは、背景の粘土だけの参照の動画になります
  • fps をそろえる: 参照の動画はテイクの fps のまま書き出します (既定の収録は 24fps)。モデルが別の fps を前提にしていると速さが変わるので、モデルに合う fps で録ってください
  • 縦横比は Blender のシーンの出力のままです。モデルが決まった比率しか受けないときは、シーンの出力の解像度を先に合わせます
  • 人の写真を外のサービスに送るときは、写っている人の同意を取ってください

Files for video generation

From a trkAR take, trkAR Camera 0.10.21+ writes the intermediate files for any video generation model that accepts a reference video and reference images with a text prompt. trkAR does not generate anything itself, and no model or service is assumed.

Select a take and press 生成用の素材を書き出す (write files for generation) in the 録画・テイク panel. The files go to <take>/for_generation/ (an earlier one is kept as for_generation_<date>/):

  • reference.mp4 — the take's camera move over the set rendered in plain gray clay; the actor is a white outline (filled black). Use it as the reference video (<Video 1>)
  • layout.png — the location seen from where the actor stands (forward, right, back, left). Reference image (<Picture 1>)
  • actor.jpg — the clearest, largest frame of the actor with the background grayed out. Reference image (<Picture 2>)
  • prompt.txt — a prompt template that refers to the files above; add your shot description at the end
  • first_frame.png (first frame of the plate), camera.json (camera per frame), manifest.json (what each file is and how to map it)

Tips: the actor outline needs a person mask (turn on MASK or DPT on the iPhone, or use the AI cut-out RVM で切り抜く on the PC, while recording); the video keeps the take's frame rate, so record at the rate your model expects; trim with the range to the model's length limit; get consent before sending someone's photo to an external service.
