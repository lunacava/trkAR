Integration (connect to your own cloud or tools)

trkAR never uploads your takes anywhere. To connect to S3, Google Drive, Frame.io, a NAS at your studio and so on, use the after-take command in the Blender add-on trkAR Camera to run a script you provide.

  • Hook: runs your command when a recording stops and when an export finishes. It passes the take location and more as arguments and environment variables, and shows the result in the panel
  • Take folder: the layout of take.json, frames, depth and the exported video
  • Automation port: external tools can open scenes, select takes and export over HTTP on 127.0.0.1
  • Data from the iPhone: OSC (camera position, rotation, timecode), NDI® video and depth, uncompressed depth (UDP)

The spec is INTEGRATION.md (in Japanese), and the example is examples/s3_upload.py (uploads a take to Amazon S3).

Build it with a coding agent such as Claude

Get this repository and ask the agent "make a hook that uploads trkAR takes to my ___". CLAUDE.md in the repository tells the agent how to do it and what to follow (for example, never writing credentials into files).

git clone https://github.com/lunacava/trkAR.git
cd trkAR
claude   # "Make a hook that uploads takes to my S3 bucket my-bucket"

Install the Blender add-on

Download trkar_camera-<version>.zip (artrk_camera-… up to 0.9.x) from Releases and install it in Blender 4.2 or later with Edit > Preferences > Add-ons > ▼ > Install from Disk. NDI needs an NDI runtime such as NDI Tools. The add-on is GPL-3.0-or-later.
