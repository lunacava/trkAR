はじめかた

iPhone / iPad の trkAR で撮ったカメラの動きで、Blender のカメラを動かし、テイクを録って書き出すまでの流れです。

iPhone trkAR ──OSC (カメラの位置・向き・画角)──▶ Blender のカメラが同じように動く
   │    ▲                                      │
   │    └── NDI「Blender (trkAR)」(カメラ視点) ─┤  iPhone の MONI で CG を見ながら撮れる
   └── NDI「trkAR」(実写) ──▶ Blender の中で人と CG を重ねる

1. 用意するもの

  • ARKit に対応した iPhone / iPad (iOS 16 以降)。深度は LiDAR のある機種 (Pro 系) の背面カメラで出ます
  • Mac か Windows の PC と Blender 4.2 以降 (5.1 以降をおすすめ。画面をそのまま NDI で送るのは 5.3 以降)
  • NDI Tools (無料)。映像の送受信に使います
  • iPhone と PC を同じネットワークに。有線 LAN が安定します。Wi-Fi は混んでいると映像がカクつきます

2. アプリ (iPhone / iPad)

  1. App Store から trkAR (英語のストアでは trkAR Cam) を入れ、カメラ・ローカルネットワーク・マイクを許可します
  2. 横向きで起動し、周りをゆっくり見回します。左上の WLDtrk の下が Mapped になれば準備完了です
  3. 床を決めます。床が見つかると自動で決まります。決まっていないときは、画面中央の十字を床に向けて AIM AT THE FLOOR ▸ TAP TO SET GND (か上の列の SET GND) を押します
  4. ✱ (設定) の PC IP Address に PC の IP、Port に 8000 を入れます (PC の IP は Mac なら システム設定 > ネットワーク、Windows なら ipconfig)

3. Blender アドオン

  1. Releases から trkar_camera-<版>.zip を落とし、Blender のウィンドウにドラッグ&ドロップします (編集 > プリファレンス > アドオン > ▼ > ディスクからインストール でも)
  2. macOS では、システム設定 > プライバシーとセキュリティ > ローカルネットワーク で Blender をオンにして、Blender を起動し直します (いちばん多いつまずきです)
  3. 試すシーンは サンプルのシーン (駅のホーム・教室) が使えます

4. つなぐ

  1. 3D ビューで N キーを押してサイドバーを出し、trkAR タブを開きます
  2. Blender でカメラを撮りたい場所に置き、trkAR 受信 の ▶ を押します。テンキー 0 (カメラ視点) にして iPhone を動かすと、カメラが同じように動きます
  3. 実写も使うときは、iPhone の CAM を入れ、trkAR 受信 で実写 (NDI) のソースに <iPhone の名前> (trkAR) を選びます。人だけを残すなら iPhone の MASK も入れます
  4. iPhone で CG を見ながら撮るときは、NDI 送出 でカメラ視点を送り、iPhone の MONI で <PC の名前> (Blender (trkAR)) を選びます

5. 録って書き出す

  1. 録画・テイク の REC (か iPhone の REC) で、タイムラインを再生しながらカメラの動き・実写・深度を録ります。もう一度押すか、再生を止めると終わります
  2. テイクを再生 で録ったテイクを見直し、CG やライトを直します。ライブに戻る で受信に戻ります
  3. 書き出し でカメラ視点を render.mp4 にします
  4. 動画生成 AI に渡すなら、生成用の素材を書き出す で中間ファイルを作ります → 生成用の素材

テイクは、保存した .blend の隣の trkar_takes/ に take_日付_時刻/ として残ります。

うまくいかないとき

症状確かめること
カメラが動かないパネルの 受信 n 件 / UDP m が 0 なら、Blender のローカルネットワークの許可・iPhone の PC IP Address と Port・同じネットワークか。姿勢 ○ Hz が出ていれば届いています
CG の床と実写の床が合わないiPhone で床が決まっているか (パネルに「床が未設定」と出ていないか)。十字を床に向けて SET GND をやり直す
NDI のソースが出ないNDI Tools が入っているか。同じネットワークか。会社や学校の Wi-Fi は端末どうしの通信が止められていることがあります
映像がカクつく・遅れるiPad / iPhone と PC を有線 LAN に。iPhone の CAM Resolution と MONI Resolution を Low に。iPhone が熱い (HOT) なら冷やす
実写が灰色・白3D ビューがソリッド表示。マテリアルプレビューにする

そのほかは サポート へ。アプリとアドオンの版の組み合わせは INTEGRATION.md の 5 章 にあります (どの組み合わせでも動きます)。

Getting started

  1. You need an ARKit iPhone / iPad (iOS 16+, LiDAR for depth), a Mac or Windows PC with Blender 4.2+ (5.1+ recommended), NDI Tools, and both on the same network (wired is the most stable)
  2. App: install trkAR Cam from the App Store and allow camera, local network and microphone. Look around until WLDtrk shows Mapped. The floor is set automatically once found; otherwise aim the center crosshair at the floor and tap AIM AT THE FLOOR ▸ TAP TO SET GND. In ✱ Settings, enter your PC's IP and port 8000
  3. Add-on: get trkar_camera-<version>.zip from Releases and drop it on Blender. On macOS, turn on Blender in System Settings > Privacy & Security > Local Network and restart Blender. Try the sample scenes
  4. Connect: in the 3D view press N, open the trkAR tab, place the camera and press ▶ on trkAR 受信 (receive). Turn on CAM on the iPhone and choose <iPhone> (trkAR) to bring in the live video; send the camera view with NDI 送出 and watch it on the iPhone with MONI
  5. Record and export: REC records the camera move, video and depth while the timeline plays; テイクを再生 plays a take back; 書き出し exports render.mp4; 生成用の素材を書き出す writes the files for video generation models — see Generation

Trouble? Check that the panel's packet counter goes up (Blender's local network permission, the PC IP and port on the iPhone), that the floor is set on the iPhone, and use wired networking if the video stutters. More on Support.
