サポート

不具合の報告やご質問は、GitHub Issues にお寄せください。お使いの機種・iOS のバージョン・trkAR のバージョン (設定 → About → Credits に表示) を書いていただけると助かります。

動作環境

  • iOS 16 以降、ARKit に対応した iPhone / iPad
  • 深度の送出には LiDAR (背面) または TrueDepth (前面) カメラが必要です
  • PC と連動させるときは、iPhone / iPad と PC を同じネットワークにつないでください

よくある質問

PC にデータが届かない
設定画面の PC IP Address とポート (OSC の既定は 8000) が、受け取る側の設定と同じか確かめてください。初回起動時の「ローカルネットワーク」の許可が必要です (iOS の設定 → プライバシーとセキュリティ → ローカルネットワーク)。

NDI のソースが一覧に出ない
同じネットワーク上で NDI を送出している PC が必要です。一覧の rescan を押してください。NDI については ndi.video をご覧ください。

PC がなくても試せますか
デモシーンで、床に動物を置いて AR の動きを確かめられます。

Support

Please report bugs or ask questions on GitHub Issues. It helps if you include your device model, iOS version and trkAR version (shown in Settings → About → Credits).

Requirements

  • iPhone or iPad with ARKit support, iOS 16 or later
  • Depth output needs a LiDAR (back) or TrueDepth (front) camera
  • To work with a PC, connect the device and the PC to the same network

FAQ

No data arrives on my PC
Check that the PC IP Address and port in Settings (OSC default: 8000) match the receiver. trkAR needs Local Network access (iOS Settings → Privacy & Security → Local Network).

No NDI sources are listed
You need a PC sending NDI on the same network. Tap “rescan”. See ndi.video for more about NDI.

Can I try it without a PC?
Yes — the demo scenes let you place AR animals on the floor.
